# 《牛来》游戏概念文档 (Game Concept)

> 版本：v0.1（Phase 1 概念孵化）｜ 作者：文策渊 (design-strategist) ｜ 日期：2026-08-17
> 关联文档：core-loop.md、level-design.md ｜ 美术基调见 art-bible.md（由 art-director 维护）

## 1. 一句话 Pitch

《牛来》是一款明快易读的横板像素跑酷游戏：操控小牛「牛来」在精心设计的关卡中奔跑、跳跃、滑铲、冲刺，以最少的失误冲过终点旗——易上手、难精通，每次重试都更接近完美。

## 2. 设计支柱 (Design Pillars)

设计支柱是后续所有系统 / 关卡 / 美术决策的唯一裁决标准。任何功能若违背支柱，应被砍掉或重做。

| # | 支柱 | 含义 | 反例（红线信号） |
|---|------|------|------------------|
| P1 | 易读优先 (Readability First) | 像素轮廓清晰、配色高对比、障碍意图一眼可辨；玩家不需要猜。 | 同屏信息过多、障碍与背景溶色、靠运气过关。 |
| P2 | 节奏感驱动 (Rhythm-Driven Flow) | 关卡如乐谱，跑 / 跳 / 滑 / 冲的时机构成可习得的心流节奏。 | 输入延迟、节奏断裂、随机惩罚。 |
| P3 | 关卡即可习得的挑战 (Levels as Learnable Challenges) | 关卡制、递进式教学，每关教一个新机制，难度锯齿上升。 | 无尽模式、无教学直接高难、难度断崖。 |
| P4 | 即时反馈正循环 (Instant Feedback Loop) | 操作 / 收集 / 评价即时反馈，重试成本极低，鼓励精进。 | 反馈滞后、死亡惩罚重、卡关无出路。 |

## 3. MDA 框架分析

### Mechanics（机制 / 规则层）
- 移动：默认向右自动奔跑；可短暂加速（可选）。
- 动词：跳 (Jump)、滑 (Slide)、冲 (Dash，带冷却)、暂停 / 重开。（滑 / 冲为**逻辑动词**而非独立渲染态：渲染上滑复用 run 帧 + 代码 squash、冲复用 run 帧 + 代码残影；权威动画映射见 level-1-spec.md §6 与 asset-spec.md §1.4。）
- 物理：重力、水平速度、AABB 碰撞、落地判定。
- 收集：金币（路径引导 + 奖励路线）、终点旗。
- 失败：撞击 / 坠落 → −1 HP；hp=0 才失败并重生 / 重试（扣血制，详见 core-loop.md §3.1 / §4）。
- 评价：星级（完赛 / 收集 / 无伤）。

### Dynamics（动态 / 玩家行为层）
- 连跳保速、滑铲穿低障、冲刺破阵等动词组合涌现的走线策略。
- 风险回报：走金币奖励高路线（险）vs 稳妥低路线（稳）。
- 重试循环：低成本重试 → 记忆关卡 → 精进走线 → 刷星。

### Aesthetics（美学 / 情感体验层）
依据 LeBlanc 八类美学，本作主目标：
- **Sensation**：明快像素视觉、顺滑动画。
- **Challenge**：技巧挑战、刷星 / 竞速。
- **Discovery**：隐藏金币路线、关卡探索。
- （弱）Expression / Fellowship：MVP 不做社交，扩展期考虑分享 / 排行榜。

情感关键词：流畅、掌控、小有成就、轻松不焦虑。

## 4. 目标玩家与 Bartle 类型映射

| Bartle 类型 | 适配度 | 在本作中的体现 |
|-------------|--------|----------------|
| Achiever 成就型 | 高 | 三星评价、最快通关时间、全收集。 |
| Explorer 探索型 | 中高 | 隐藏金币路线、关卡秘密、章节叙事碎片。 |
| Socializer 社交型 | 低（MVP） | MVP 单人；扩展期加排行榜 / 截图分享。 |
| Killer 杀手型 | 不适用 | 无 PvP / PvE 对抗，不服务此类型。 |

**目标玩家画像：**
- 休闲核心玩家：短会话（3–5 分钟一关）、PC + 移动双端。
- 易上手难精通爱好者：喜欢「一命通关 / 全收集」挑战。
- 轻量 / 亲子玩家：明快像素风、低挫败、无血腥。

## 5. 范围分层 (Scope Tiers)

### MVP（可玩竖切）
- 3–5 关，单章节。
- 核心动词：跑（自动）/ 跳 / 滑 / 冲。
- 障碍 ≥3 种（地刺、低悬障碍、深坑）。
- 金币收集 + 终点旗 + 1–3 星评价。
- 键盘 + 触摸输入，基础 HUD（金币数 / 计时 / 暂停）。
- 选关界面 + 关卡进度本地保存。

### 完整版
- 15–20 关，分 3–4 章节，难度曲线完整。
- 更多机制：移动平台、可破坏物、滚动障碍、轻量敌人。
- 每关隐藏挑战目标（如「无伤通关」「限定时间」）。
- 世界观叙事碎片（条目 / 过场）。
- 本地排行榜、设置与可访问性选项（色盲模式、震动反馈）。

### 扩展（愿景）
- 关卡编辑器 + 社区分享。
- 每日挑战、云存档、装饰皮肤（换色牛来）。
- 原声音乐、多平台发行（Steam / 移动商店）。

## 6. 设计红线自检（Phase 1）

- **主导策略**：Dash 设冷却且仅短距；低悬障碍不可冲过（必须滑），避免单一万能动词。
- **经济失衡**：金币仅用于装饰 / 解锁，不影响通关能力；关卡靠「通关」解锁而非金币堆量。
- **认知过载**：同屏 ≤2 决策点；障碍高对比；机制逐步教学。
- **支柱漂移**：所有机制服务 P1–P4；不引入养成 / RPG 等偏离系统。
