# 《牛来》核心循环文档 (Core Loop)

> 版本：v0.1 ｜ 作者：文策渊 (design-strategist) ｜ 关联文档：concept.md、level-design.md

## 1. MVP 玩家动词 (Player Verbs)

动词是玩家能「对游戏世界做的原子动作」。MVP 动词保持精简，降低认知负荷（支柱 P1）。

| 动词 | 默认输入 | 作用 | 机制约束 |
|------|----------|------|----------|
| 跑 Run | 自动（向右） | 持续前进，基础位移 | 默认速度 V_run；可选短暂加速 |
| 跳 Jump | 跳键 | 越过地刺 / 间隙 | 单跳；受重力 G；有最大跳高 / 距离 |
| 滑 Slide | 滑键 | 下蹲滑铲，穿低悬障碍 | 持续时长 T_slide；期间非无敌 |
| 冲 Dash | 冲键 | 短距冲刺，破阵 / 抢时机 | 冷却 C_dash；距离短；**不可破低悬障碍** |
| 暂停 Pause | Esc | 暂停 / 菜单 | 非战斗动词 |
| 重开 Retry | R | 重开本关 | 失败后低成本重试，维持心流 |

> 红线：Dash 不可作为万能解（低悬障碍必须滑、部分间隙必须跳），避免主导策略。

## 2. 输入映射 (Input Mapping)

### 2.1 键盘 (PC)

| 动作 | 键位 |
|------|------|
| 跳 | Space / W / ↑ / K |
| 滑 | S / ↓ / L |
| 冲 | Shift / J（带冷却） |
| 加速（可选） | → / D 按住 |
| 暂停 | Esc / P |
| 重开 | R |

### 2.2 触摸 (移动端)

单手可玩布局（屏幕分区 + 固定按钮）：
- 上滑 / 点按屏幕上半 → 跳
- 下滑 / 点按屏幕下半 → 滑
- 右下角固定 [冲] 按钮（带冷却环）→ 冲
- 右上角 [⏸] 按钮 → 暂停
- 死亡后自动弹出 [重开] 大按钮

> 注：触摸区可在「分区手势」与「三按钮固定布局」间由 art-director / UX 最终定稿，两种均满足 P1（易读优先）。

## 3. 循环图 (Loop Diagram)

### 3.1 微观循环（单次尝试 / 单段）

```
[奔跑自动前进]
      │
      ▼
[读障：识别前方障碍 / 金币]  ◄── 高对比易读 (P1)
      │
      ▼
[玩家输入: 跳 / 滑 / 冲]  ── 节奏时机 (P2)
      │
      ▼
[碰撞判定]
      │
  ┌───┴──────────┐
  ▼              ▼
[过障成功]   [撞击 / 坠落: −1 HP]
  │              │
  │        ┌─────┴──────────┐
  │        ▼                ▼
  │   [hp > 0: 继续]    [hp = 0: 失败界面]
  │   (扣血容错, P4)        │
  │        │                ▼
  │        │            [重试 / 选关]
  └────────┴────────────────┘
      │
      ▼
[收集金币 / 抵达终点旗]
```

### 3.2 宏观循环（单关）

```
[选关] → [微观循环 × N 段] → [抵达终点旗]
                                │
                                ▼
                         [结算: 时间 / 收集 / 无伤]
                                │
                        ┌───────┴───────┐
                        ▼               ▼
                  [解锁下一关]      [重玩刷星 / 收集]
```

### 3.3 元循环（进度）

收集反馈 → 解锁新章节 / 装饰 → 回归选关 → 新机制教学 → …

## 4. 心流与难度曲线原则

- **心流条件**：挑战 ≈ 技能。每关前半教学、后半考核，使玩家技能随关卡成长。
- **锯齿上升曲线**：新机制只在已掌握基础后出现；每 3–4 关引入 1 个新障碍；章末设整合长关（难度峰），之后回落。
- **低重试成本 + 即时反馈** → 维持心流、降低焦虑（P4）。采用**扣血制**（建议 `MAX_HP = 3`，单次失误 −1 而非立即失败）：既保留对单次失误的宽容（不频繁中断心流），又通过「血量耗尽才失败」提供真实惩罚，与 P4 可调和。
- **认知负荷上限**：同屏同时只呈现 1–2 个决策点；障碍用轮廓 + 配色高对比区分（P1）。
- **难度不靠「随机」或「堆量」**，靠「时机 / 走线」的组合（P2 / P3）。
