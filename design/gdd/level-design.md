# 《牛来》关卡设计框架 (Level Design)

> 版本：v0.1 ｜ 作者：文策渊 (design-strategist) ｜ 关联文档：concept.md、core-loop.md

## 1. 关卡结构 (Level Structure)

关卡制（非无尽）。每关是一条有限的横向赛道。

| 维度 | MVP 设定 |
|------|----------|
| 长度 | 单关 30–60 秒单程；世界宽度约 1500–3000 px（按 V_run 换算） |
| 组织 | 按「段落 (Segment)」串联，每段一个挑战焦点 |
| 主目标 | 抵达终点旗 (primary，必达成) |
| 次级目标 | 收集 ≥X% 金币；无伤；限时（扩展） |
| 评价 | 1–3 星（见下） |
| 进度 | 通关解锁下一关；星级与金币本地保存 |

### 星级评价 (Star Rating)
- ★：抵达终点旗。
- ★★：抵达终点 + 收集全部金币（或时间达 B 级）。
- ★★★：抵达终点 + 全收集 + 无伤（或时间达 A 级）。

> MVP 采用「完赛 / 全收集 / 无伤」三条件，直观且服务 Achiever（见 concept.md）。

## 2. 障碍类型与机制 (Obstacles) — MVP ≥3

| # | 障碍 | 解法动词 | 机制要点 | 教学关 |
|---|------|----------|----------|--------|
| O1 | 地刺 / 尖桩 (Ground Spike) | 跳 | 地面静态突出；触碰 −1 HP（扣血） | L1 |
| O2 | 低悬障碍 / 管道 (Low Overhang) | 滑 | 高处悬空；站立 / 冲会撞，必须滑 | L2 |
| O3 | 深坑 / 间隙 (Gap/Pit) | 跳 / 冲 | 地面断裂；坠落 −1 HP | L1 / L3 |
| O4* | 滚动障碍 / 移动锯 (Moving Hazard) | 时机 + 跳 / 滑 | 周期移动；需读节奏 | L4+ |
| O5* | 可破坏木箱 (Breakable) | 冲 | 冲刺撞碎，开路 | L3+ |

> O4 / O5 为 MVP 可选扩展；MVP 至少含 O1–O3。\* 标注的为扩展机制。

## 3. 关卡节奏与教学安排

### 教学原则
- 每关 = 1 个新机制「首秀」（安全低压力示范）→ 简单组合 → 考核段。
- 新机制只在已掌握前置后出现（L1 跳 → L2 滑 → L3 冲 + 综合 → L4 移动障碍）。
- 首秀处给视觉提示（浮动图标 / 虚线落点），之后撤除，逼玩家内化。

### 单关节奏模板（6 段）
1. **暖身**：纯奔跑 + 首个金币直线引导（教「自动跑 + 收集」）。
2. **教学段**：引入障碍 A，间距宽、无惩罚压力。
3. **巩固段**：障碍 A ×2–3，加入金币奖励路线。
4. **引入障碍 B**，与 A 交错。
5. **综合段**：A + B（+ 间隙）组合，节奏加快。
6. **终点冲刺**：短距 + 终点旗 + 结算。

### 多关卡递进（MVP 5 关示例）

> **MVP 范围确认（用户拍板）**：采用 **5 关**（L1–L5）作为第一批测试关，不缩减为 3 关。下表即 MVP 关卡清单。

| 关 | 主题 | 新机制 | 整合度 |
|----|------|--------|--------|
| L1 草甸起跑 | 跳（地刺 / 间隙） | 跳 | 单一 |
| L2 管道农庄 | 滑（低悬） | 滑 | 跳 + 滑 |
| L3 箱庭窄道 | 冲（破箱 / 抢距） | 冲 | 跳 + 滑 + 冲 |
| L4 风车作坊 | 移动障碍 | 时机 | 全动词 + 动态 |
| L5 牛来大道 | 章末整合长关 | — | 综合考核 |

## 4. 第一关草案 (Level 1 — 「草甸起跑」)

- **主题**：阳光草甸，明快，教学友好。
- **教学焦点**：自动奔跑 + 跳跃越地刺 + 基础收集。
- **世界宽度**：≈1800 px；预计 35–40 秒。
- **评价**：★ 完赛 / ★★ 全收集（约 15 金币）/ ★★★ 全收集 + 无伤。

### 段落布置（坐标 = 世界 X，单位 px）

| X 区间 | 内容 | 设计意图 |
|--------|------|----------|
| 0–300 | 平地，3 枚金币直线排列 | 暖身，教「自动跑 + 收集」 |
| 300–500 | 单根地刺（首秀），上方浮动「↑跳」提示 | 教学：跳越静态障碍 |
| 500–800 | 地刺 ×2 间隔，刺间放金币 | 巩固：精准跳 + 奖励 |
| 800–1100 | 1 个深坑（宽 ≈80 px），坑上方金币 | 教：跳跃间隙 |
| 1100–1400 | 地刺 + 间隙组合，节奏稍快 | 综合：前学组合 |
| 1400–1700 | 分支：高路线（跳台 + 金币）vs 低路线（稳妥） | 风险回报，服务 Explorer |
| 1700–1800 | 终点旗 + 结算 | 收尾 |

### 教学提示（仅首秀出现）
- 第一根地刺上方浮动「↑跳」图标。
- 首次间隙前地面画虚线落点提示。
- 之后撤除，玩家内化节奏（P2 / P3）。

## 5. 设计红线自检

- **主导策略**：L1 不提供「冲」万能解；间隙必须跳、地刺必须跳，避免单一动词通关。
- **认知过载**：L1 同屏 ≤1 决策点；地刺 / 坑用高对比色（红刺 / 深色坑）。
- **支柱漂移**：L1 全程服务 P1（易读）/ P2（节奏）/ P3（教学），无偏离系统。
- **经济**：金币仅评星用，不影响通关（无 P2W）。
