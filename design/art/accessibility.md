## 1. 可访问性分级（Accessibility Tier）

本项目 Phase 1 目标分级：**Basic**（基础可访问性）。

> 分级定义（本项目采用，逐级包含）：
> - **Basic**：核心可读性 + 必要对比度 + 基础输入容错。
> - **Standard**：在 Basic 上增加色觉无障碍模式、键位重映射、字幕。
> - **Comprehensive**：在 Standard 上增加完整辅助选项、减少动态、音频可视化和高对比度 UI。
> - **Exemplary**：在 Comprehensive 上增加全面自定义、眼动/单开关等极端适配。
>
> 本项目先达 **Basic**，预留升级到 **Standard** 的接口（色盲模式开关、键位重映射预留）。是否升级由用户/主理人确认。

## 3. 色觉无障碍（Color Vision）

- **原则**：颜色**不是**唯一信息载体。所有状态用「形状 + 图标 +（可选）颜色」三重编码。
- **具体应用**：
  - 障碍/危险：警示红 `#D64545` **+ 尖刺/锯齿形状**，不靠纯红辨识。
  - 收集物：金币/爱心 **+ 明确图标轮廓**，不靠纯黄辨识（避免与牛来金 `#E8B30F` 混淆）。
  - 生命：红心图标，额外数量数字「x3」辅助。
  - 过关/失败：除颜色外有图标（✓/✗）与文字提示。
- **预留**：提供「色盲安全模式」开关，将红→橙黄、绿→蓝青等安全映射，复用 art-bible §2 调色板。
- **牛来金冲突规避**：牛来主体为金色，收集物改用浅金 `#F4C63F` 并加图标，危险用红，三者色相/明度均拉开，降低色盲误读。

## 4. 对比度要求（Contrast）

- **文字**：`#FBF3E0`（奶白） on `#1A1423`（夜墨） ≈ **14:1**（远超 4.5:1）。
- **UI 控件**：亮元素（金 `#E8B30F`）与暗底 `#1A1423` 对比 ≥ 3:1；面板内描边 `#2F1300` 保证边界清晰。
- **游戏内可读**：HUD 文字叠加在场景上时，加半透明暗底 `#1A1423`@70% 保证 ≥ 4.5:1。
- **地面/背景**：可落脚点（草绿 `#5FB049`）与背景（天空蓝 `#8FD3E8`）明度差 ≥ 3 档，确保落地判定可辨（见 art-bible §6）。
- **禁用**：低对比文字（如浅灰 on 白）、纯装饰性弱对比 UI。

## 5. 输入辅助选项（Input Assistance）

- **判定容错**：跳跃/落地判定窗口宽松（coyote time + jump buffer），降低操作精度要求。
- **重试零惩罚**：死亡/失败一键重试（R 或按钮），无进度损失焦虑。
- **暂停可达**：任意时刻可暂停（Esc / 按钮），暂停菜单大按钮、高对比。
- **预留键位重映射**：将输入抽象为「跳跃/暂停/确认」动作，配置文件预留重映射（升 Standard 时启用）。
- **减少动态（预留）**：提供「减少特效」开关，关闭屏幕震动、限制粒子（Comprehensive 接口）。
- **触控/宽判定（移动端预留）**：若出移动端，按钮区域 ≥ 44px 等效，避免误触。

## 6. 验收检查清单（Basic）

- [ ] 所有正文/分数文字对比度 ≥ 4.5:1（用对比度工具校验）
- [ ] 障碍、收集物、生命均有非颜色辨识特征
- [ ] 最小字号达标，HUD 有暗底保证可读
- [ ] 暂停/重试路径清晰可达
- [ ] 跳跃判定含 coyote time / buffer
- [ ] 色盲模式开关接口已预留（不强制启用）
